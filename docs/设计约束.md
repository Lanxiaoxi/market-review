# 收盘复盘仪表盘 · 设计约束

> 本文档是「收盘复盘仪表盘」的单一视觉与交互规范来源（Single Source of Truth）。
> 任何二次开发（新增页面、新增图表、接入真实数据）都必须遵守本文档，以保持统一风格。

---

## 1. 设计原则

1. **理性、安静**：整体克制，无装饰性渐变、无重阴影、无可爱元素、无重科技感。
2. **单一强调色**：交互元素只用一种蓝色；其余颜色均为「中性灰 + 行情语义色」。
3. **红涨绿跌**：行情数据的涨跌严格遵循 A 股惯例（涨 = 红，跌 = 绿），与欧美相反。
4. **发丝边，不用阴影**：卡片层级靠「1px 浅灰描边 + 白底 + 背景色差」区分，不使用投影。
5. **数字等宽**：所有行情数字用等宽数字（tabular-nums），保证对齐、易扫读。
6. **最小化动效**：处理态不使用 spinner；仅按钮按压、hover 背景等轻量反馈。持续上传/传输类动作才可保留动效。
7. **信息层级清晰，但不密集**：个人复盘场景，避免专业金融终端的密排，区块之间留足呼吸空间。

### 2.2 字体

| 用途 | 字体栈 |
|---|---|
| 中文 / 全站默认 | `"Noto Sans SC", "PingFang SC", "Microsoft YaHei", -apple-system, "Segoe UI", sans-serif` |
| 数字 | `"Inter", ...`（同一栈内优先），并叠加 `font-variant-numeric: tabular-nums` |

- **不强制加载 web font**（避免国内环境首屏慢）；数字靠 `tabular-nums` 实现等宽观感。
- 中文与数字字体栈合并为同一 `--font-sans` 变量。

## 3. 布局规范

```
┌──────────┬──────────────────────────────────────────┐
│ 侧栏 240 │  内容区（padding 28，垂直 gap 24）           │
│  · brand │  · 页面标题栏（标题 + 副标题 | 日期/操作）    │
│  · 导航  │  · 区块 1（如 8 张指数卡，wrap 网格）         │
│  · 用户  │  · 区块 2（主图 + 侧卡，gap 16）             │
└──────────┴──────────────────────────────────────────┘
```

- **左侧栏固定 240px**，右侧内容区自适应剩余宽度。
- 内容区为**单列垂直流**，区块之间统一 24px 间距，不做多列嵌套滚动。
- 页内区块遵循「一个主导区块 + 次级区块」的层级，避免等权并列。
- 导航顺序（当前五页）：`今日总览 → 自定义图表 → 板块轮动 → 自选跟踪 → 策略画板`。
- **自定义图表页**：图表卡采用**一行两卡网格**（`grid-template-columns: 1fr 1fr`，gap 16px），新增图表自动换行；该页**不提供拖入 / 上传入口**，图表卡下方保留「从图表库添加图表」占位槽（图表库角色，支持页内新增/管理）。
- **今日总览页「我的图表」区块**：占位语义为「从自定义图表页选择图表钉到主页」，非上传；已钉选槽展示迷你图表 + 右上角「已钉选」chip（accent 蓝状态点），空槽保留「选择图表」占位。

## 4. 组件规范

### 4.1 侧栏导航项

- 结构：`图标(18×18) + 文本栈（标题 13px/600 + 副标题 10px）`，水平排列，gap 10。
- 内边距 `10px 12px`，圆角 10px。
- **默认态**：标题 `--ink`，图标 `--icon`，无背景。
- **选中态**：背景 `--active-bg`，标题 `--accent`。
- **hover 态**：背景 `#f2f4f8`（略深于 active-bg 的中性灰，与选中态区分）。

### 4.2 卡片

- 白底 `--card` + 1px `--border` 发丝边 + 圆角 12px，**无阴影**。
- 内边距 `18px 20px`，内部垂直 gap 14 或 16px。

### 4.3 指数卡（数据卡）

- 宽 162px，结构：`名称(13px muted) → 数值(19px/600 ink) → 涨跌幅(13px 红/绿) → sparkline`，gap 3。
- 涨跌幅统一格式 `+18.45  +0.55%`（金额与百分比，两个空格分隔）。

### 4.4 分段控件（Segmented）

- 容器背景 `--chip-bg`，圆角 8px，内边距 3px，gap 2px。
- 段：圆角 6px，默认透明 + `--muted` 文字；选中段白底 + `--ink` 文字（600 字重）。

### 4.5 主按钮（胶囊）

- 背景 `--accent`，白字 13px/500，圆角 9999px，内边距 `7px 14px`。
- 按压态 `transform: scale(0.96)`。

### 4.6 状态 Chip

- 背景 `--chip-bg`，圆角 9999px，内边距 `5px 10px`。
- 结构：`状态点(6×6 圆点) + 文本(12px)`。

### 4.7 表格 / 列表行

- 表头：12px `--muted`，下内边距 8px。
- 数据行：垂直内边距 10px，无横向边框（靠行高与对齐分隔）。
- 对齐：名称左对齐，数字右对齐；涨跌幅 / 盈亏用红绿色。
- **金额列头必须显式标注单位**（如「现价（元）」「今日盈亏（万）」），同表单位不一致时尤其必要。

### 4.8 汇总卡（指标）

- 指标块：`数值(24px/600) + 标签(12px muted)`，垂直排列，gap 4。
- 多个指标块水平 `space-between` 分布。

### 4.9 占位卡（选择图表 / 添加指标）

- 高 120–150px，背景 `--placeholder` + 发丝边 + 圆角 12px。
- 居中「+ 图标(20×20 `--placeholder-icon`) + 提示文字(12px muted)」，gap 8。
- 语义：从「自定义图表页」选择已有图表钉到总览页；**全站不支持拖入 / 上传文件**。

## 5. 图表规范

- 图表统一使用**内联 SVG**（折线用 `polyline`，柱用 `rect`，网格线用 1px `rect`），不引入第三方图表库时可保持原生一致；若换 ECharts，配色与线宽必须对齐下表。

| 要素 | 规范 |
|---|---|
| 折线线宽 | 2px（sparkline 1.5px） |
| 折线端点 | `stroke-linecap: round`、`stroke-linejoin: round` |
| 网格线 | `--grid`（`#f2f2f4`），零线 / 基线 `--grid-strong`（`#e8e8ec`），1px |
| 坐标轴刻度 | 12px `--muted`，SVG `text` 直接渲染 |
| 柱状填充 | 涨 `--up`、跌 `--down`、平/中性 `--series-base`、成交量柱 `--bar-fill` |
| 系列色（多线） | 第 1 系列 `--ink`（黑）、第 2 系列 `--accent`（蓝）、第 3 系列 `--series-purple`（紫） |
| 基准 / 对比线 | `--series-base`（灰） |

- 图表留白：绘图区与卡片边距保持 ≥ 20px；时间轴刻度放在图下方，右对齐末位。

## 6. 数据语义（红涨绿跌）

- **涨 / 正收益 / 涨停 / 上涨家数 → `--up`（红 `#d04545`）**。
- **跌 / 负收益 / 跌停 / 下跌家数 → `--down`（绿 `#2f9e6e`）**。
- **平盘 / 中性 / 基准 → `--series-base` 或 `--muted`**。
- 数值格式：金额千分位逗号，百分比保留两位小数，正数显式带 `+`，负数带 `-`。
- 所有数据为示意样例时，页脚须标注来源 / 说明。

---

## 7. 交互与动效

- **导航切换**：点击即时切换页面，active 项同步高亮，无过渡动画。
- **分段控件**：点击在所属容器内切换 active 段，**只影响本卡**，不联动其他区块（周期切换仅重绘本图）。
- **按钮按压**：`scale(0.96)` 微反馈。
- **hover**：可交互元素用背景 / 透明度变化（如导航项 hover 背景、按钮 hover 无位移）。
- **禁用 / 处理态**：不用 spinner；用文字或 tooltip 提示，或直接禁用（降低透明度）。
- **持续上传 / 传输**：仅此类长时动作允许动效。

## 9. 常见违规（红线）

- ❌ 引入第二种强调色（所有「可点击」都必须是 `--accent` 蓝）。
- ❌ 给卡片 / 按钮 / 文字加阴影（阴影只属于「产品图」，本仪表盘不使用）。
- ❌ 用装饰性渐变作背景。
- ❌ 涨用绿、跌用红（违反 A 股惯例）。
- ❌ 正文用 500 字重（阶梯是 400/500/600，正文 400，强调 500，标题 600）。
- ❌ 全圆角图块或混用圆角语法（卡片 12 / 导航 10 / 分段 8·6 / 胶囊 9999，不做中间值）。
- ❌ 处理态用 spinner。
