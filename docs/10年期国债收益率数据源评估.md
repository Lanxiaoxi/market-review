# 10年期国债收益率数据源评估

> 结论：程序化获取选**财政部页面背后的中债接口**（yield.chinabond.com.cn），历史深度和数据结构都更友好；货币网只适合"最近一年"的轻量取数。

## 两个页面背后的真实接口

两个页面的数据都不在 HTML 里，背后都是一个 POST JSON 接口，均无登录、无验证码，普通浏览器 UA 即可调通。

### 1. 中国货币网（CFETS 口径）

- 页面：`https://www.chinamoney.com.cn/chinese/sddsintigy/`（壳页面，内容异步加载）
- 接口：`POST https://www.chinamoney.com.cn/ags/ms/cm-u-bk-currency/SddsIntrRateGovYldHis?lang=CN&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&pageNum=1&pageSize=N`
- 返回：`records[]` 中 `dateString` / `oneRate`（1年期）/ `tenRate`（10年期，4位小数），例如 `"tenRate":"1.7093"`
- 限制：**只提供最近 1 年历史**（JSON 与 Excel 导出接口均如此），超出返回 `flagMessage: 只提供一年历史数据查询及下载`
- 只含 1 年期、10 年期两个期限

### 2. 财政部页面 → 中债（CCDC 口径）

- 页面：`https://gks.mof.gov.cn/gzsylqs/gzlssj/` 只是个 iframe，指向 `https://yield.chinabond.com.cn/cbweb-czb-web/czb/showHistory?locale=cn_ZH&nameType=1`
- 接口：`POST https://yield.chinabond.com.cn/cbweb-czb-web/czb/historyQuery?startDate=...&endDate=...&gjqx=0&locale=cn_ZH&qxmc=1`
- 返回：`heList[]` 一次给整条曲线：`threeMonth/sixMonth/oneYear/twoYear/threeYear/fiveYear/sevenYear/tenYear/thirtyYear`（10年期即 `tenYear`，2位小数）
- 历史深度：页面 JS 有"查询不超过 1 年"的校验，但**仅前端校验，服务端不强制**——实测 6.5 年范围（2020 起）一次拉回 410KB 数据正常；2018 年以前返回空，疑似还有隐藏上限，稳妥做法是按年分段拉取
- 注意：响应中 `qxmc`（曲线名称）字段乱码（编码问题），数值字段均正常，不影响使用

## 对比

| 维度 | 货币网 (CFETS) | 财政部→中债 (CCDC) |
|---|---|---|
| 10年期字段 | `tenRate`，4位小数 | `tenYear`，2位小数 |
| 历史深度 | 严格 1 年 | 至少 6.5 年，建议按年循环 |
| 一次请求内容 | 仅 1Y/10Y | 全曲线 9 个期限 |
| 反爬 | 无（实测不带 Referer 也行） | 无，但大范围请求别太频繁 |

## 选用建议

- 只要最近一年内的数据：货币网更简单，字段直白，一次 POST 搞定。
- 要做历史回测/长序列：选**中债接口**，否则货币网需每天定时抓取累积才有历史。
- 两者是**两条不同的官方曲线**：货币网是外汇交易中心（CFETS）曲线，中债是中央结算公司（CCDC）曲线，同日数值有细微差异（如 2026-08-28 分别为 1.7093% 与 1.69%）。金融媒体常引用的"10年期国债收益率"一般指中债口径。
